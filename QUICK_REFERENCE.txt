## ⚠️ Common Errors & Fixes

| Error | Fix |
|-------|-----|
| Port 8000 in use | Close other app or use: `python app.py --port 8001` |
| ModuleNotFoundError | `pip install -r requirements.txt` |
| Model not found | `python train_model.py` |
| Frontend can't connect | Ensure backend running on 8000 |
| Image rejected | Upload clear oral cavity image |
| npm not found | Install Node.js from nodejs.org |

## 🎯 API Quick Reference

### Test with curl
```bash
# Check status
curl http://localhost:8000/status

# Make prediction
curl -X POST -F "file=@image.jpg" http://localhost:8000/predict
```

### Endpoints
- `GET /` - API info
- `GET /status` - API status
- `POST /predict` - Make prediction
- `POST /validate-image` - Validate without predicting

## 💡 Tips & Tricks

### For Better Predictions
- Use high-quality images (224x224+ pixels)
- Ensure good lighting
- Clear, unobstructed oral cavity view
- Multiple angles for variety

### For Faster Development
- Keep terminals open while working
- React hot-reloads on file save
- Backend auto-reloads on file change
- Use browser DevTools (F12) for debugging

### For Deployment
- Build frontend: `npm run build` (creates optimized build)
- Use Docker for consistency
- Enable monitoring and logging
- Setup automated backups

## 🎓 Image Requirements

### ✅ Upload These
- Clear oral cavity images
- High quality, well-lit
- Unobstructed views
- Standard image formats (JPG, PNG)

### ❌ Don't Upload These
- Animals, birds, insects
- Persons or faces
- Everyday objects
- Blurry images
- Files > 10MB
